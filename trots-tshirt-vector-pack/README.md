## Production notes

- SVG format with transparent backgrounds.
- All lettering is built from vector geometry. There are no font dependencies.
- No linked raster images are used.
- Resize proportionally; do not stretch artwork.
- Before production, ask the printer to confirm the final print width for each garment size.
- Colours are specified in RGB/HEX. The printer should create CMYK or spot-colour separations for the selected fabric and printing process.
- For dark garments, the printer should use an appropriate white underbase where required.
- The colourful designs are suitable for DTF/DTG or separated screen printing.
- The conservative designs are suitable for screen printing, DTF/DTG, or embroidery after digitising.
